## 1.1 完成物デモ(6分)

**ゴール**: 「この講座は動画に鍵をかける話だ」と一言で分かり、自分にはまだ作れないと気づいた状態。

**流れ**:
- [フック] 動画を売るサイトを作るとき、いちばん難しいのはどこか。UIでもDBでもなく、「買った人にだけ見せる」ところ
- [画面] 完成したLMSのコース一覧 → レッスンを開いて再生。ここまでは普通
- [核心] 再生中の動画URLをネットワークタブからコピーする。**シークレットウィンドウに貼る → 403**
- [間] ここで一拍置く。「これ、自分の作りかけのアプリでやったら、たぶん見れてしまいます」
- [画面] 管理画面から受講期限を昨日に書き換える → リロード → 同じ人なのに403
- [説明] この3つの画面で起きていることを最後まで実装しきるのが、この講座
- [予告] 使うのは Next.js と Postgres と R2 と Stripe。ただし主役は技術の名前ではなく、権利をどこで確認するかという設計

**キーフレーズ**: 「動画を置くのは簡単です。見せないようにするのが難しい」

**次への繋ぎ**: では、この講座で何を作って、何を作らないのかをはっきりさせます。

## 1.2 この講座が答える一つの問いと、作らないもの(6分)

**ゴール**: 講座の問いと範囲が頭に入り、期待とズレていないか自分で判断できる状態。

**流れ**:
- [説明] 世の中の「LMSを作る」教材の多くは、コースとレッスンのCRUDで終わる。動画は公開URLに置きっぱなし
- [核心] この講座を貫く問いは一つ。**買った人にだけ、期限つきで、動画を見せる**。全レクチャーがこの問いに紐づく
- [画面] curriculum.md を映して9セクションを俯瞰。S5とS6が山場だと先に言う
- [説明] 作らないものを先に宣言する。SNSログイン、掲示板、モバイルアプリ、SCORM、多言語、クーポン
- [説明] 前提知識: TypeScriptの基本文法、Reactのコンポーネントが書ける、SQLのSELECT/JOINが読める。DDDやインフラの知識は要らない
- [予告] 次は環境を立てて、配布コードの歩き方を決める

**キーフレーズ**: 「機能を数える講座ではなく、一本の問いを最後まで詰める講座です」

**次への繋ぎ**: 手を動かせる状態を作りましょう。

## 1.3 環境構築とタグの歩き方(6分)

**ゴール**: 手元でアプリが起動し、任意のレクチャーの開始状態に飛べる状態。

**流れ**:
- [画面] リポジトリをclone。Node22の確認、`pnpm install`
- [画面] `docker compose up -d` でPostgres。`pnpm db:migrate` → `pnpm dev` で起動
- [核心] 配布コードはディレクトリではなく**gitタグ**で分けている。`git checkout l52-start` で「5.2の開始状態」に飛ぶ
- [説明] 詰まったら `lNN-complete` を見れば必ず動くものがある。差分は `git diff lNN-start lNN-complete` で読む
- [説明] エディタは何でもよい。自分はnvimを使うが、VS Codeでも同じ手順で通る
- [予告] 次はコードではなく、作るサービスの業務ルールを読む

**キーフレーズ**: 「迷子になったら complete タグに戻ればいい、と思って進めてください」

**次への繋ぎ**: 実装の前に、何を守るシステムなのかを決めます。

## 1.4 業務ルールを読む(7分)

**ゴール**: 5つの名詞とルール10項目が頭に入り、「支払いの事実」と「視聴する権利」が別物だと納得した状態。

**流れ**:
- [画面] domain-requirements.md を開いて上から読む。3ロールと5つの名詞の表
- [説明] Course/Lesson/Progress は素直。問題は Purchase と Enrollment
- [フック] なぜ「買った」と「見られる」を別のテーブルに分けるのか。1つでよさそうに見える
- [核心] 返金されたときを考える。支払いの事実は帳簿として残す必要があるが、見る権利は消さないといけない。同じ行にあると剥がせない
- [説明] Enrollment は「誰が・どのコースを・いつまで」の3つ組。この3つ組がこの講座の主人公
- [説明] 残りのルールをざっと読む。署名URLは短命、決済判定はWebhook、同じイベントが二度来ても二重に作らない、返金で失効
- [間] 「今このルール全部、どこに実装するか想像つきますか」
- [予告] 次のセクションで、この5つの名詞をテーブルに落とす

**キーフレーズ**: 「払った事実は消えない。見る権利は消える。だから分けます」

**次への繋ぎ**: では、この3つ組をスキーマにしていきます。
